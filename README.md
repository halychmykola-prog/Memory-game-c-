# Memory-game-c-
DN


Memory game che viene fatto in c++ 

Il procedimento e' diviso in parti diverai: 2 ore spente per versione troppo complicata con la idea del codice sbagliata

Le ore succesive sono state divisi per:

1. capire uno dei metodi piu migliori per lavorare con la matrice
2. creare parte del codice per riempire matrice con alfabeto, creare alfabeto, riempire matrice con coppie delle lettere
3. togliere errori del passagio num 2
4. finire il codice con procedimento del gioco e output interpretabile per l'utente
